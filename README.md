My Daily Planner
This is a simple yet elegant daily planner application designed to help you organize your tasks efficiently. It is built using HTML, CSS, and JavaScript to showcase my proficiency in front-end web development.

🚀 Features
Add Tasks: Enter tasks along with their time and add them to the list.

Task Completion: Mark tasks as completed with a simple click.

Delete Tasks: Easily remove any task from the list.

Responsive Design: Fully responsive design to work seamlessly on both desktop and mobile.

🛠 Technologies Used
HTML: For the basic structure of the web page.

CSS: To style the web page with a modern, clean look.

JavaScript: To manage task data and interactivity, such as adding, completing, and deleting tasks.

🎨 Design Highlights
Minimalistic Layout: The design focuses on simplicity with a soft pastel color palette for a calm and easy-to-use interface.

Interactive Elements: Buttons and task list items have smooth hover effects, giving the app a polished and professional feel.

Responsive: The application adjusts to different screen sizes, making it mobile-friendly and user-friendly on all devices.

⚙️ How to Use
Type a task into the text input field.

Set a time for your task using the time input.

Press the "Add Task" button to add your task to the list.

You can mark tasks as completed or delete them using the buttons next to each task.
